# MawaHub — Ideas That Change the World

African-led impact platform founded by **Benny Peter**, headquartered in Kenya and Tanzania.

## Website
This repository contains a responsive 40-page website foundation with shared navigation, footer, routing, design system, impact pillars, founder story, education, marketplace, donations, partnerships, community, blog and events.

## Production integrations
Payment, authentication, live impact data, forms, maps, translation APIs and admin CMS should be connected with real credentials before production. The UI intentionally does not claim to process payments until those services are configured.
